# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: open the [Security tab](https://github.com/melihcolpan/flask-restful-login/security) of this repository and choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and the commit you tested. You will get a reply as soon as possible, and the fix will credit you unless you prefer otherwise.

## Supported versions

This is an example project without versioned releases. Fixes are made on the `master` branch.
